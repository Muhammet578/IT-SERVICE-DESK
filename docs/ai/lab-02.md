3.1. Реализация PDO

PDO (PHP Data Objects) предоставляет единый интерфейс для работы с различными системами управления базами данных.

Для выполнения запросов используются методы prepare() и execute().

Пример подготовленного запроса:

$sql = "SELECT * FROM tickets WHERE id = :id";

$stmt = $this->pdo->prepare($sql);
$stmt->execute(['id' => $id]);

$ticket = $stmt->fetch(PDO::FETCH_ASSOC);

Параметр :id передаётся отдельно от SQL-команды, что обеспечивает безопасную обработку значения.

3.2. Реализация MySQLi

MySQLi используется для взаимодействия с MySQL через специализированный интерфейс PHP.

Для выполнения параметризованных запросов используются prepare(), bind_param() и execute().

Пример:

$sql = "SELECT * FROM tickets WHERE id = ?";

$stmt = $this->mysqli->prepare($sql);
$stmt->bind_param('i', $id);
$stmt->execute();

$result = $stmt->get_result();
$ticket = $result->fetch_assoc();

$stmt->close();

Здесь i обозначает целочисленный параметр.

4.1. Переключение драйвера базы данных

Для выбора способа подключения используется параметр DB_DRIVER, расположенный в файле .env.

Пример настройки PDO:

DB_DRIVER=pdo

Для переключения на MySQLi:

DB_DRIVER=mysqli

В зависимости от значения параметра приложение использует соответствующую реализацию TicketRepositoryInterface.

Такой подход позволяет изменять способ работы с базой данных без переписывания методов репозитория или HTTP-маршрутов.

6.4. Использование транзакций

При выполнении функциональных тестов используется механизм транзакций.

Перед проверками вызывается beginTransaction() или begin_transaction(), а после тестирования — rollBack() или rollback().

Таким образом, тестовые изменения отменяются, а база данных не заполняется временными заявками после запуска тестов.
