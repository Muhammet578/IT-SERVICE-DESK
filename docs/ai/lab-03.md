# Лабораторная работа №3
## Разработка веб-приложения IT-SERVICE-DESK на Symfony 7.4

### 1. Цель работы
Изучить архитектуру MVC, маршрутизацию, контроллеры,
шаблонизатор Twig и функциональное тестирование Symfony.

### 2. Используемые технологии
- PHP 8.4.27
- Symfony 7.4.23 LTS
- Twig
- PHPUnit 13.4.8

### 3. Архитектура приложения
- Controller — обработка HTTP-запросов
- Service — предоставление демонстрационных данных
- Twig — отображение HTML-страниц

### 4. Реализованные возможности
- Страницы пользователей и IT-заявок
- Маршрутизация через атрибуты, YAML и PHP
- JSON-ответы
- Обработка HTTP 404
- Получение параметров HTTP-запроса

### 5. Тестирование
Результат PHPUnit: 6 tests, 18 assertions.
Проверка YAML: 24 файла без ошибок.
Проверка Twig: 8 файлов без ошибок.
