# Лабораторная работа №6 — Безопасность, роли и авторизация

**Проект:** IT-SERVICE-DESK  
**Стек:** PHP 8.4, Symfony 7.4, Doctrine ORM, MariaDB, Twig, Bootstrap 5  
**Ветка:** `lab-06`  
**Дата подготовки документа:** 26.11.2026

## Цель

Реализовать безопасную аутентификацию и разграничение доступа к функциям системы управления IT-заявками, защитить изменяющие операции и проверить права различных категорий пользователей.

## Адаптация учебного задания

Вместо учебных `SalesOrder` и `ROLE_SALES` в предметной области IT-SERVICE-DESK используются `Ticket` и `ROLE_TECHNICIAN`. Контроль операций `VIEW`, `EDIT`, `CHANGE_STATUS`, `DELETE` реализуется через `TicketVoter`. Роли: `ROLE_USER`, `ROLE_TECHNICIAN`, `ROLE_MANAGER`, `ROLE_ADMIN` с соответствующей иерархией.

## Реализованные компоненты (по ходу разработки)

- Пользователь (`App\\Entity\\User`) реализует интерфейсы `UserInterface` и `PasswordAuthenticatedUserInterface`; email уникален.
- Хеширование паролей и аутентификация Symfony Security; страницы login и logout, создание аккаунтов через доступный менеджерам маршрут `/users/new`.
- Доступ по ролям через `config/packages/security.yaml` и серверные проверки контроллеров.
- `TicketVoter` для просмотра, редактирования, смены статуса и удаления заявок.
- Проверка активности аккаунтов с помощью `UserChecker`; ручная проверка блокировки и восстановления входа выполнялась при разработке.
- Личный профиль `/profile`.
- Session: выбранный период статистики Dashboard и фильтр заявок; хранение пароля в Session не требуется и не допускается.
- CSRF в форме входа и POST-удалении заявки.
- Ролевое отображение действий в Twig, списки и формы заявок, статистика и фильтры.
- Две темы интерфейса — Classic и Vice City — не изменяют серверную логику разрешений.

> Важно: это перечень реализованных по ходу разработки функций, **а не протокол независимой проверки каждой из них**. Результаты финальных тестов необходимо заполнить ниже.

## Финальная проверка

Запуск из `symfony-app/`:

```powershell
php bin/console lint:twig templates/
php bin/console lint:container
php bin/console debug:config security
php bin/console debug:router
php bin/console doctrine:schema:validate
php bin/phpunit
```

`debug:router` должен содержать маршруты входа, выхода, профиля, списка/создания пользователей, заявок, изменения статуса и удаления. `debug:config security` — подтверждать фактические роли, иерархию и ограничения доступа.
